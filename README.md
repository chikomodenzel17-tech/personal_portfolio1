# Personal Portfolio

A static portfolio website built with HTML, CSS, and JavaScript.

## Project structure

```text
personal_portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

Open `index.html` in a browser to view the portfolio. Image and icon files are
stored locally under `assets/`.
